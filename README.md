## 📖 About the Repository

This repository serves as a personal learning journal and code archive for exploring 2D vector graphics, coordinate systems, mathematical transformations, and algorithmic rendering using the **PyCairo** library.

---

## 📚 Topics Covered

* 📐 **Basic Graphic Primitives:** Drawing lines, polygons, rectangles, circles, and arcs.
* 🔄 **Canvas Transformations:** Working with local coordinate space via `ctx.translate()`, `ctx.rotate()`, and `ctx.scale()`.
* 🎨 **Color & Styling:** RGBA color spaces, line caps, stroke widths, and fill patterns.
* 🌈 **Gradients & Patterns:** Linear and radial gradient implementations.
* ➰ **Complex Paths & Curves:** Custom paths, Bézier curves, and clipping regions.
* 🖼️ **Image Export:** Rendering vector graphics directly into PNG and SVG formats.

---

## 🛠️ Tech Stack & Prerequisites

* **Language:** Python 3.x
* **Primary Library:** [PyCairo](https://www.google.com/search?q=https://pycairo.readthedocs.io/)

### Installation

Make sure you have Python installed, then install `pycairo` via `pip`:

```bash
pip install pycairo

```
